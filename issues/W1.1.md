# [W1.1] A Socket class that closes itself (RAII)
labels: week:1, size:S
groups: A, B

**Size:** S (1 day) · **Needs:** nothing, start now · **Language topic:** classes, destructors, RAII, move-only types

## What is this, in plain words?
A socket is a file descriptor: an `int` the kernel gives you. You must
`close()` it exactly once. Forget, and you leak it (the server eventually runs
out); close it twice, and you might close somebody else's new socket.

C++ solves this with **RAII**: wrap the `int` in a class whose **destructor**
calls `close()`. Then the socket is closed automatically when the object goes
out of scope, even if an exception is thrown. Every program your group writes
for the next 8 weeks uses this class.

## What you must give back
In `src/socket.hpp` and `src/socket.cpp` (in your group's folder):
```cpp
class Socket {
public:
    Socket() = default;                    // an empty socket (fd = -1)
    explicit Socket(int fd);               // takes ownership of fd
    ~Socket();                             // closes the fd, if any
    Socket(Socket&& other) noexcept;       // moving takes the fd; `other` becomes empty
    Socket& operator=(Socket&& other) noexcept;
    Socket(const Socket&) = delete;        // no copies: two copies would close the fd twice
    Socket& operator=(const Socket&) = delete;
    int fd() const;
    bool valid() const;                    // fd != -1
};

Socket listen_tcp(std::uint16_t port);     // socket + SO_REUSEADDR + bind 127.0.0.1:port + listen
Socket accept_client(const Socket& listener);
Socket connect_tcp(const std::string& host, std::uint16_t port);
void send_all(const Socket& s, std::span<const char> data);    // loops until every byte is sent
std::size_t recv_some(const Socket& s, std::span<char> buffer); // one recv; returns 0 at end of stream
```

## Step by step
1. Write the class. The move constructor takes `other.fd_` and sets `other.fd_ = -1`, so only one object owns the fd. The move assignment first closes its own fd (if any), then takes the other's.
2. `listen_tcp`: `socket(AF_INET, SOCK_STREAM, 0)`; set `SO_REUSEADDR` with `setsockopt` (so you can restart the server straight away; Learn first explains why); fill a `sockaddr_in` for 127.0.0.1 and the port (`htons`!); `bind`; `listen(fd, 128)`. Wrap **every** call in `check(...)`.
3. `connect_tcp`: use `getaddrinfo` to turn the host and port into an address, then `socket` and `connect`. Remember to `freeaddrinfo`.
4. `send_all`: `send` can send fewer bytes than asked. Loop until everything is sent. Use the flag `MSG_NOSIGNAL`, so writing to a closed connection gives an `EPIPE` error instead of killing the program with `SIGPIPE`.
5. `recv_some`: one `recv`, checked. Returns the number of bytes read, and 0 when the other side has closed.

## How to test it
`tests/test_socket.cpp` (it's built automatically):
- a moved-from `Socket` is not `valid()`, and the moved-to one has the fd;
- after a `Socket` goes out of scope, its fd is closed (`fcntl(fd, F_GETFD)` then fails with `EBADF`);
- `listen_tcp(0)` works (port 0 means "any free port"), and `connect_tcp` to it succeeds;
- `send_all` of 10 MB to a connected socket, while another thread reads, delivers every byte.
