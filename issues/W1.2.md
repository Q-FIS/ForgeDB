# [W1.2] The echo server
labels: week:1, size:M
groups: A, B

**Size:** M (2-3 days, good for a pair) · **Needs:** W1.1 (start with raw calls, and switch to the `Socket` class when it's merged)

## What is this, in plain words?
The simplest possible server: it sends back every byte it receives. It's small,
but it has every networking trap in it: TCP delivers data in unpredictable
pieces, `send` can send less than asked, and clients can vanish at any moment.
Get this right and the HTTP server next week is "just" parsing.

## The contract (the test checks this)
`apps/echo_server.cpp`, run as `<g>_echo_server --port <N>`. It accepts
connections on 127.0.0.1:N, and for each one sends back every byte it receives
until the client closes its side, then closes the connection. One client at a
time is fine this week.

## Step by step
1. Read `--port N` from the command line (`argv`). Print a clear message and exit with code 2 if it's missing.
2. `listen_tcp(port)`, then loop forever: `accept_client`, then handle that client.
3. Handling a client: loop `recv_some` into a buffer (64 KB is good), then `send_all` exactly the bytes you received. Stop when `recv_some` returns 0.
4. **A client that vanishes:** `send_all` can throw (`EPIPE` or `ECONNRESET`). Catch `std::system_error` **around one client**, print it to stderr, and go back to `accept`. One bad client must never stop the server.
5. Ignore `SIGPIPE` for the whole process at startup (`signal(SIGPIPE, SIG_IGN)`), as a second safety net.
6. Delete the placeholder body (the `return 77`).

## Watch out for
- Echo exactly the number of bytes `recv` returned, not the whole buffer.
- Don't print every byte or message: printing is slow, and the test sends 100 MB.

## How to test it
```bash
cmake --build --preset debug -j && ctest --preset debug -R echo --output-on-failure
```
`tests/echo_test.py` sends 100 MB and compares checksums, sends data 1 byte at a time, and kills a client mid-message (with a TCP reset) to check the server survives. Try it by hand too: `./build/debug/group-a/a_echo_server --port 9000`, then `nc localhost 9000` in another terminal.
