# [W3.A1] A bounded queue (template, condition variables)
labels: week:3, size:S
groups: A

**Size:** S (1 day) · **Needs:** nothing · **Language topic:** templates, `std::mutex`, `std::condition_variable`

## What is this, in plain words?
The heart of a thread pool: a queue that one thread pushes connections into and
worker threads pop from. It's **bounded** (it has a maximum size), so that when
the server is overloaded, it refuses work instead of queueing forever. You did
a version of this in lab L3; now you make it a reusable C++ template.

## What you must give back
`src/bounded_queue.hpp` (a template, so it's all in the header):
```cpp
template <typename T>
class BoundedQueue {
public:
    explicit BoundedQueue(std::size_t capacity);
    bool try_push(T item);             // false immediately if the queue is full (never waits)
    std::optional<T> pop();            // waits for an item; nullopt once closed and empty
    void close();                      // wake every waiting pop(); no more pushes accepted
    std::size_t size() const;
};
```
`T` will be `Socket`, which is move-only, so use `std::move` when storing and returning items.

## Step by step
1. Inside: a `std::deque<T>`, a `std::mutex`, a `std::condition_variable`, the capacity, and a `bool closed`.
2. `try_push`: lock; if closed or full, return false; otherwise push, unlock, and `notify_one`.
3. `pop`: lock; `cv.wait(lock, [&]{ return closed || !items.empty(); })`; if there's an item, move it out and return it; otherwise return `std::nullopt`.
4. `close`: lock, set `closed`, unlock, `notify_all`.

## How to test it
`tests/test_bounded_queue.cpp`: capacity is respected; `pop` waits until there's a push (use a thread); `close` wakes a waiting `pop`; and 4 producers plus 4 consumers move 1 million items with none lost or duplicated. **Run it on the `tsan` preset.**
