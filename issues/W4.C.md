# [W4.C] Write the comparison, and present it
labels: week:4, size:S
groups: A, B

**Size:** S (1 day) · **Needs:** W4.A3 and W4.B3. **One person from each group writes this together**: the two issues (one per group) are the same job.

## What is this, in plain words?
The point of building two servers: what does each design do well, what breaks
it, and what should the final service in weeks 5-8 use?

## Step by step
Write `docs/server-comparison.md`:
1. **The table:** both groups' numbers side by side (requests per second, p50, p99, memory, CPU) for each test in W4.A3.
2. **What broke each design:** the thread pool with many idle connections (each one holds a worker); the event loop with a slow handler (it blocks everyone).
3. **The decision:** our proposal for the final service: B's event loop for the connections, plus A's worker pool for the slow work, with the loop never blocking. Write the 3-4 hardest questions this raises (for example: how does a worker hand a finished response back to the event loop?).
4. **Present it** in the week-4 wing session: 20 minutes per group, design first, then the numbers.
