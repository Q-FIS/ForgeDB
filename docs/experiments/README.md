# Experiments

Each experiment issue ends with a one-page report here, `<issue-id>-<name>.md`,
written so that someone who wasn't there can repeat it and trust it.

```markdown
# <What we wanted to know, as a question>
**Issue:** CONN-6 · **Who:** <name> · **Commit:** <git rev-parse --short HEAD>

## Setup
Machine (CPU, cores, RAM), build preset (release!), exact commands.

## Results
A table (and a chart if it helps). Several runs: report the median and the spread.

## What it means
2-5 sentences: the answer to the question, and *why*, in terms of what the
OS or the CPU is doing.

## What surprised us
```
