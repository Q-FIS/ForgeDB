# Members

Your first PR (the warm-up, Day 1): add a file here called `<your-github-name>.md`,
like this one. Everyone writes a different file, so nobody gets a conflict.

```markdown
# Your Name (@your-github-name)
- **Component:** e.g. WAL (from the kickoff)
- **C:** 1-5 (1 = never used it, 5 = very comfortable)
- **C++:** 1-5
- **Linux terminal:** 1-5
- **I want to learn:** one or two sentences
- **My labs repo:** https://github.com/<you>/qfis-labs
```

Be honest about the numbers: they help the captain pair people up, nothing else.
